# GenericAmountInput

Uncontrolled currency text input — right-aligned, `input input-xs input-secondary`, placeholder `0.00`. The unbound primitive behind `AdjustmentInput` and `TotalInput`; use it directly when you don't need the adjustment store.

```jsx
<GenericAmountInput id="budgeted" name="budgeted" defaultValue="125.00" />
```
