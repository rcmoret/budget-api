# NeighborLinks

Previous/next month pager with arrow affordances, built on Inertia `Link`. Needs a live Inertia router to navigate.

```jsx
<NeighborLinks
  previousMonth={{ href: "/budget/2026/01", label: "January" }}
  nextMonth={{ href: "/budget/2026/03", label: "March" }}
/>
```
