# BudgetSummaryComponent

Labelled summary block: a titled list of label/amount pairs on a `bg-base-200` panel, where the fourth row is separated by a secondary rule to read as a total.

```jsx
<BudgetSummaryComponent
  label="February"
  values={[{ key: "income", label: "Income", amount: { cents: 480000 } }]}
/>
```
