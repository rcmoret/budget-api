# CardRow

Horizontal row inside a card. Right-aligns content and pushes the last child to the far right, which is what gives every card the same action-on-the-right rhythm. `minHeight="lg"` reserves a taller row so content doesn't jump when a form opens.

```jsx
<CardRow minHeight="lg"><span>Budgeted</span><AmountSpan amount={12500} /></CardRow>
```
