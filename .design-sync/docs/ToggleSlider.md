# ToggleSlider

SVG on/off switch. With `onClick` it renders as a real `role="switch"` button; without one it is a read-only indicator. Always give it `ariaLabel` or `ariaLabelledby` when interactive.

```jsx
<ToggleSlider toggleValue={enabled} onClick={toggle} ariaLabel="Show cleared" />
```
