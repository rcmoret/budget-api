# Icon

FontAwesome glyph by friendly name — `name` is looked up in the component's own dictionary (`"trash"`, `"plus-circle"`, `"caret-down"`, `"folder-open"`, `"money-check"`, …) and falls through to the raw string when unknown.

```jsx
<Icon name="coins" />  <Icon name="caret-right" />
```

The app loads FontAwesome from a CDN kit script; this bundle ships FontAwesome
Free 6 locally so the glyphs render here too.
