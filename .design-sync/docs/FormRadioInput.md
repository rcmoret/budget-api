# FormRadioInput

Uncontrolled radio row for plain HTML form submission — takes `name`, `value` and `defaultChecked` rather than `checked`/`onChange`. Exported from `components/radio`; the controlled sibling is `RadioInput`.

```jsx
<FormRadioInput name="account_type" value="cash_flow" defaultChecked>
  Cash flow
</FormRadioInput>
```
